# Behavioral Design Patterns Using PHP

This project contains all 11 GoF Behavioral Design Patterns listed in Laboratory Activity #4.

## Requirements
- PHP 8.1 or newer
- Visual Studio Code (or any text editor)
- A web browser

## How to run
1. Extract this project folder.
2. Open `behavioral-patterns` in VS Code.
3. Open Terminal > New Terminal.
4. Check PHP is available by running: `php -v`
5. Start the PHP development server from the project root:
   `php -S localhost:8000`
6. Open the pattern you want in your browser, for example:
   `http://localhost:8000/01-chain-of-responsibility/`
7. Change the URL folder name to run another pattern.

## Four suggested patterns for video demonstration
- Iterator
- Strategy
- Observer
- Memento

## Folder contents
Each pattern folder contains:
- `classes.php` - interfaces and classes for the pattern
- `index.php` - demonstration program

## Notes
- The examples use simple sample data and do not connect to a real database.
- The weighted grade example uses Quiz 20%, Exam 40%, and Project 40%.
- The transmuted grade example is a simple demonstration formula, not an official school grading policy.
- Review and understand each example, and follow your instructor's directions about coordinating pattern choices with classmates.
